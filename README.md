# CorkBoard

Превратите рабочий стол в пробковую доску: ваши фото раскладываются на текстуре пробки в виде полароидов, марок и стикеров и ставятся обоями одним нажатием.

**Требования:** Mac на Apple Silicon или Intel, macOS 14 или новее.
## Установка

1. Скачайте **CorkBoard.dmg** по кнопке выше (или со страницы [релизов]([CorkBoard.dmg](https://github.com/gor60k/CorkBoard/releases/download/v0.1.0/CorkBoard.dmg))).
2. Откройте скачанный файл. Появится окно с приложением и папкой **Applications**.
3. Перетащите **CorkBoard** на папку **Applications**.
4. Закройте окно образа и извлеките его (кнопка ⏏ рядом с «CorkBoard» в боковой панели Finder). Скачанный файл можно удалить.

## Первый запуск

Приложение распространяется не через App Store и не подписано платным сертификатом Apple, поэтому при первом запуске macOS покажет предупреждение вроде «Apple не удалось проверить, что приложение не содержит вредоносного ПО». Это нормально: исходный код открыт и лежит в этом репозитории. Разблокировать приложение нужно один раз.

**Способ А. Через настройки (без терминала)**

1. Откройте CorkBoard из папки «Программы». Появится предупреждение, закройте его кнопкой «Готово».
2. Откройте **Системные настройки → Конфиденциальность и безопасность**.
3. Прокрутите вниз до сообщения о CorkBoard и нажмите **«Всё равно открыть»**.
4. Подтвердите паролем или Touch ID. Дальше приложение будет открываться как обычно.

**Способ Б. Через Терминал**

```bash
xattr -dr com.apple.quarantine /Applications/CorkBoard.app
```

После этой команды приложение запускается двойным щелчком без предупреждений.

## Как пользоваться

1. Нажмите **«Добавить фото»** и выберите картинки (или перетащите их в окно).
2. Приложение само разложит их на доске. Результат виден в превью.
3. Нажмите **«Экспорт»**, и доска станет обоями на всех подключённых экранах.

Доска сохраняется автоматически, при следующем запуске вы продолжите с того же места.

## Где хранятся данные

Фото и состояние доски лежат в папке:

```
~/Library/Application Support/CorkBoard/
```

Оригиналы ваших файлов не изменяются: приложение работает с копиями.

## Удаление

1. Перетащите CorkBoard из «Программ» в корзину.
2. Если хотите стереть и данные, удалите папку `~/Library/Application Support/CorkBoard/`.

Обои, которые вы уже установили, останутся: их можно сменить в *Системных настройках → Обои*.

## Если что-то не работает

- **«Приложение повреждено» или не открывается**: выполните команду из «Способа Б» выше.
- **Обои не обновились**: откройте [Issues](https://github.com/ВАШ-НИК/CorkBoard/issues) и опишите проблему, указав версию macOS.

## Сборка из исходников

1. Установите Xcode.
2. `git clone https://github.com/ВАШ-НИК/CorkBoard.git`
3. Откройте `CorkBoard.xcodeproj` и нажмите **Run** (⌘R).
